# CycloneDX Property Taxonomy Coordination — `atis:telecom5g`

**Status: informative publication/coordination material.**

The `atis:telecom5g:*` properties are intended for interoperable public use in the ATIS/QSCII Telecom5G CBOM profile. CycloneDX permits custom properties without formal registration, while encouraging property names of interest to the general public to be registered in the CycloneDX Property Taxonomy. Formal registration is optional and is therefore **not** a condition of CBOM conformance.

CycloneDX Property Taxonomy repository: https://github.com/CycloneDX/cyclonedx-property-taxonomy

## Version 1.0.0 coordination status

The Version 1.0.0 package includes `cyclonedx_property_taxonomy_manifest.json`, a registration-ready inventory of the namespace and current property names. It is intentionally **not described as an official upstream submission format** and is not evidence that CycloneDX has accepted or registered the namespace.

ATIS/QSCII should decide whether to submit the public namespace/property inventory upstream and identify the appropriate organizational maintainer/contact. That governance action can proceed independently of profile conformance because CycloneDX registration is optional.

## Versioning and synchronization

The coordination manifest is generated from the same-version machine-readable taxonomy. Changes to public property names in any subsequent release should update both artifacts together. Deprecated migration-only names are included and marked deprecated so any registration discussion does not accidentally present them as recommended new-use properties.
